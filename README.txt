# 探索者図鑑サイト（試作品）

## 開き方
1. ZIPファイルを解凍します。
2. `index.html` をブラウザで開くと試作品が表示されます。

## 探索者を変更する場所
`script.js` の一番上にある `investigators` の中身を書き換えると、
名前・年齢・職業・プロフィールなどを変更できます。

## 画像について
現在は試作品として、イラストの代わりに大きな一文字を表示しています。
実際の探索者イラストを入れる機能も、次の段階で追加できます。

## 次にできること
- あなたの探索者の実データに差し替える
- イラストをカードに表示する
- 詳細ページをもっと図鑑らしくする
- URLを取得してSNSで共有できるよう公開する
